# 公开网页与官方名录数据源边界（数据源包）

本包只**声明允许的数据源与用途**；真正执行仍由 ToolBroker、`source_policy`、预算与限流强制。

## 允许的数据源

| 源 | 用途 | 个人数据类 | 备注 |
| --- | --- | --- | --- |
| searxng.search（自托管） | discovery / research | 公开组织信息 | 走平台限流；不用付费搜索 API |
| crawl4ai.fetch（自托管） | research / enrichment | 页面可能含个人数据 | robots 与域策略强制；同域礼貌间隔 |
| source_policy 管理的官方名录 | discovery | 公开组织信息 | 新域名必须先在 source_policy 登记并经运营批准 |

## 禁止

- 不在本包内新增任何源；白名单之外的源一律拒绝。
- 不绕过 robots、不批量抓取、不做登录态抓取。
- 付费数据源（海关/流量/信用等）不在 S1；如引入需单独决策。
- 抓取结果中出现的个人联系方式只用于合规复核，不得进入研究输出（见合规包）。
