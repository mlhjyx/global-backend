# 金属加工行业词表与买家角色

适用：金属加工、钣金、机加工品类的卖家获客（检索词归一、买家公司理解、买家角色匹配）。

## 分类与术语

- ISIC Rev.4：C25（金属制品）、C28（机械设备）。
- 德语核心术语：Lohnfertigung（来料加工）、Blechbearbeitung（钣金加工）、CNC-Fräsen（数控铣削）、Laserschneiden（激光切割）、Schweißen（焊接）、Metallverarbeitung（金属加工）。

## 买家角色

1. Geschäftsführer / Managing Director（总经理，决策人）
2. Head of Production / Fertigungsleitung（生产技术负责人）
3. Procurement / Einkauf（采购）
4. Technical Director / Technische Leitung（技术负责人）
