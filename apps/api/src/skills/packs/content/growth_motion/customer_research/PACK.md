# 客户研究检查单（内容包）

用途：在触达前形成对一个买家公司的最小可信画像；只作策略提示，不执行动作。

## 检查单

1. **公司与业务**：主营、产品线、站点/规模（仅公开来源）；同名公司不得混用。
2. **需求假设**：结合卖家的产品与目标市场，列出 2–3 个"可能的需求"并标注依据；未验证的假设必须明示。
3. **采购角色**：决策人/影响者/使用者；只写公开职业信息，不留个人联系方式。
4. **触发信号**：扩张、上新线、招标、展会等公开信号，附来源与日期。
5. **不确定性与缺口**：列 "未查询 / 未验证 / 空白" 三种状态，分别说明下一步怎么补齐。

## 禁止

- 不推断敏感属性（健康、宗教、政治等）。
- 不编造营收、员工数、采购量；不用付费数据源结果冒充公开事实。
