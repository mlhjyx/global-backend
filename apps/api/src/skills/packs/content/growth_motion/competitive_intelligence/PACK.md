# 竞争情报检查单（内容包）

用途：为某条线索/某次成单机会补充竞争格局判断；只作策略提示，不执行任何动作。

## 检查单

1. **对手识别**：客户可能比较的替代方案（同类制造商/分销商/平台）；只写可核实公司与产品，不臆造份额。
2. **定位差异**：从公开资料提取对方的交付周期、认证、最小起订量；与自家产品对比，未知写 "未验证"。
3. **证据链**：每个判断给来源（官网/公告/公开名录）与日期；不引用付费数据库或内部名单。
4. **赢单/输单复盘**（有历史时）：记录客户最终选择、决定因素、我方差距；只陈述事实与客户原话。
5. **输出边界**：不生成对外比较材料或贬损竞品的内容；对外使用前人工审阅。

## 禁止

- 不使用爬虫绕过访问控制的竞品资料；不抓取个人社媒。
- 不编造份额、营收、客户名；无法核实的维度明确标注。
