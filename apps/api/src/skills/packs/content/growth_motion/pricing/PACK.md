# 定价与报价检查单（内容包）

用途：配合 `quoting.incoterms_quote`（L1）形成报价建议；只作建议与证据，不产 PI/CI/PL 等对外单据。

## 检查单

1. **成本可追溯**：货值、包装、内陆运费、海运/空运、保险、关税逐项列出；每一项注明来源或假设。
2. **Incoterms 边界**：EXW/FOB/CFR/CIF/DDP 的责任与费用分界明确；所选术语与目的国一致。
3. **汇率显式**：报价币与成本币不同时，必须提供汇率与取数日期；不查外部牌价、不猜汇率。
4. **毛利与底线**：给出加成与最低毛利；低于底线时明确拒绝建议而不是硬算。
5. **合规**：出口管制/制裁复核（见合规包）；报价建议不代表正式要约，对外须人工确认与法务模板。

## 禁止

- 不生成对外单据、不发送、不承诺交期/库存。
- 不做税务或法律意见；DDP 关税仅按输入估算并标注假设。
