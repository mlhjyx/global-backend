# DACH 分销商获客动作包

适用：目标市场为德国/奥地利/瑞士的工业品类分销商获客（Understand → Discover → Qualify）。

## 动作检查单

1. **分销身份证据**（Impressum/关于页原文）：Vertrieb / Handel / Großhandel / 在售第三方品牌列表；进口商常带中国品牌。
2. **贸易角色判定**：转售型分销/批发/进口/经销 = 下游买家；制造商 = 竞品（mismatch）；撮合平台 = weak。
3. **德语检索**：Zulieferer、Großhandel、Vertriebspartner、Handelsvertretung；区域限定 DE/AT/CH。
4. **决策人**：Geschäftsführer（总经理）、Einkauf（采购）、Technische Leitung（技术）；只取页面明确出现的具名人员，不猜邮箱。
5. **触达前检查**：制裁筛查 clear、禁联名单未命中、个人数据最小化（合规包）；S1 不发送任何外部消息。

## 衡量

- 主指标：深判通过率（match / 判定总数），不降于基线。
- 辅指标：分销商 ICP 的首次回复率（M3 后才有真实发送数据）。
- 记录每步证据与来源，无法核验写 "未验证"。
