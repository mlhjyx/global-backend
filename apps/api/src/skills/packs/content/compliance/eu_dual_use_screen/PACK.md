# 欧盟双用途/出口管制复核（合规包）

适用：面向欧盟市场的获客与报价建议（L1），以及研究类技能的输出。

## 硬约束（按优先级）

1. **双用途物项对外材料需人工复核**：凡涉及 Regulation (EU) 2021/821 附件 I 所列物项（含技术资料、参数表、报价建议）的对外使用，必须先经人工确认；系统只产草稿与证据，不产对外单据。
2. **制裁潜在命中禁止触达**：`sanctions.status == potential_match` 的对象不得进入 create/engage 阶段动作；命中未清白前只能内部复核。
3. **个人数据最小化**：研究简报只保留公开职业信息（姓名职务所在公司），不得输出个人邮箱/电话；需要联系时先走合规评审。

## 证据要求

- 每条结论附来源（URL 或内部记录 id）与检索日期。
- 无法核验的维度写 "未验证"，不得推断。
- 触达前必须过制裁筛查与禁联名单；本包不改变 ToolBroker 白名单与审批链，只提供策略约束。
