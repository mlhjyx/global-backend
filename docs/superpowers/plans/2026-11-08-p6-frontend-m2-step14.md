## 3. 信息架构（Q32 落地）

- **工作台**：我的任务（进行中/待审批/待处理回复）+ 最近活动 + 空状态引导。
- **公司档案**：公司列表/详情（资料库 tab、企业事实审批、ICP）。
- **找买家**：企业库搜索（C1）+ 发掘任务创建/运行页（现有 run 页收敛）。
- **买家线索**：线索队列（needs_review/recommended/rejected）→ **提升为商机**入口。
- **商机与触达**（新一级）：
  - Campaign tab：列表/详情（计划摘要、审批卡、Why 卡三层、影子横幅「将执行但不执行」）。
  - 商机 tab：QGO 管线视图（OPEN→SAO 已接受→Outcome 登记）、证据卡。
  - 触达 tab：批次列表/草稿审批（预览/编辑/批准）/回复队列（分类结果+建议 outcome 一键确认）。
- **设置**：成员/工作空间/禁联名单（C2）/数据与隐私/审计/数据源状态（C3，只读运营信息）。
- 保留 P5 通知铃铛；影子期与「将执行」语义全局统一文案（词表）。

## 5. Playwright 主链路（验收框架）

- 用例集（8–12 条）：
  1) 注册→向导→建档（公司/产品/目标市场）；
  2) 触发 Company Understanding → 事实审批；
  3) 生成 ICP → 发起挖掘任务 → run 进度可见（逐家进度、事件流）；
  4) 线索页接受一条线索 → 提升为 QGO（证据卡可见）；
  5) 触发 Campaign 计划（mock 或本地 planner）→ 审批卡 → 批准 → 影子横幅断言（无执行按钮/禁用态）；
  6) 触达批次草稿审批（预览/编辑/批准）→（发送开关 off 时）发送按钮禁用与文案；
  7) SAO 接受 → 登记 Outcome；
  8) 设置页禁联名单增删 → 线索/触达联动文案；
  9) 零术语扫描断言（全页面文本快照 vs 禁用词表）；
  10) 错误文案三层（触发一次 402/403 断言 ErrorNotice 三层与折叠）。
- 环境：CI 起 web（vben build）+ server（BFF）+ 引擎 dev 栈 or mock 层（无法稳定提供的步骤用 BFF mock，标 `mock` 标签）。
