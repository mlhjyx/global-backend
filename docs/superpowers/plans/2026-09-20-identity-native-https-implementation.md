Test 64 KiB exact/chunked excess, 3xx no-follow, duplicate/invalid lengths and JSON fields, compressed/invalid UTF-8, DNS/address/TLS failure, timeouts/late callbacks and redaction. The loopback tests are not proof of GitHub or public DNS success.

Update descriptor/orchestration and tests in `governance-organization-identity-github-controller.mjs` / `.spec.mjs`, plus bootstrap, materialization-packet/handoff/preflight and launcher consumers discovered by exact contract-version searches. The new adapter must be included in source closure and operation profile digests; an old producer or consumer fails closed. Preserve v2 provenance instead of accepting it as v3.
4. Connect the actual execution, deadline, FD, file-set rechecks and journal lifecycle only after the complete transport/source/tool closure is frozen and reviewed. Construct operation receipts exclusively from actual observations and execution identities. A trusted receipt requires the installed producer and independent readback, not a constructor result or test fixture. Until those dependencies are available, execution remains HOLD.
5. Run affected tests, lint, docs/governance and current-worktree graph checks; one independent final code review and required in-scope fixes. Do not repeat unrelated API suites or previous stable proofs. Preserve original root and protected worktrees.

Packaging contract: ipaddr.js is imported from the existing API dependency location, and the strict parser's transitive modules are explicit source-closure dependencies. Installed code must retain verified resolution/layout or use a separately reviewed immutable bundle; a source import resolving in this worktree does not prove that an installed package is complete.

No finding was deferred.
