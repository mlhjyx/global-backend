- 起因：隔离候选代码超过复杂度预算，且原来分别从路径读取、验签和计算审批摘要，可能记录不同快照。
- 改动：验证、解析和记录同一份审批文件内容；以同一文件句柄读取受限输入，并拆分现有的范围和预算校验。经独立只读审查确认无文件级导入循环，精确登记四条守卫依赖，不更改 G16 扫描器或 G9 阈值。按同次独立审查更新 ToolBroker/Router 受保护指纹，物理调用限制保持启用。
- 测试：审批文件变动回归先失败后通过，候选脚本和 API 相关单测以及 G9 本地复核。
- 未做：未上线部署或发起真实付费调用；独立代码审查不代替 GitHub 安全扫描及运行时验收。
