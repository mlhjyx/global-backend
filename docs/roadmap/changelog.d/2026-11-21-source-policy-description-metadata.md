title: Distinguish lockfile descriptive metadata from dependency sources
---

- 起因：正常 pnpm 锁文件的 deprecated 描述含网址和多行标量时，被整文件来源扫描错误拒绝。
- 改动：仅在规范 packages 映射的包条目中，有界识别 deprecated 字符串，生成验证器内部的来源语义视图；原锁文件及安全告知字节不改。真实来源字段、凭据网址、歧义结构及越界引用仍拒绝，CI 的 trusted-base 信任入口不变。
- 测试：保留真实描述误拒及编码凭据反例的 RED，完整新旧来源套件通过；完整冻结原锁直接验证和离线审计入口另留原始回执。离线报告仅是入口测试夹具，不是实际安全候选的漏洞审计；同头全门和独立复验另行绑定。
- 未做：未改依赖、锁、镜像、审计基线、Copy 资格、业务合同、数据库或运行配置；未安装安全候选目标依赖，未解除发布者、libc、OCI 和运行采用后继门。前置源码通过不代表依赖安全、运行恢复或部署完成。
