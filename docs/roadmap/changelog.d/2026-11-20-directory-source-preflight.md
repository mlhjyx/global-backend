title: Check directory admission before crawling and model extraction
---

- 起因：独立测试目录查询找到261条记录，但来源未登记，付费抽取后全部被raw隔离。已拒绝的目录还会占据有限列表页名额。
- 改动：目录使用活动侧真实政策快照派生的检查，复用raw既有最具体域、暂停和discovery用途规则；缺上下文拒绝，获准目录才计页数，每页和Broker来源锚点在抽取前复核。保留原页面作为分页与每页身份基址，不把经过隐私归一的来源锚点当导航地址；原有raw/SQL、robots、出网、回执和预算门继续复核。
- 测试：先取得政策前置、混合空结果及分页锚点回归的RED，相关单元和覆盖检查随修复转GREEN；活动测试验证模型filters不能自行批准来源。其余lint、build、文档、治理及CI结果随PR核验。
- 未做：不新增或放宽来源政策，不宣称恢复261家公司；不实施SourceCapability整体架构，不改资格门、财务UNKNOWN处置、历史运行或账本，不修改生产。原信号失败的诊断与可恢复性另列，不能以本补丁冒充已恢复。
