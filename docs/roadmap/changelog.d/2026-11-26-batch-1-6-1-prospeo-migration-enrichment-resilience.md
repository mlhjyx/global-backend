- 起因：Batch 1.6 上线后在意大利光伏试点工作区现网实测商业查邮暴露三类卡点：(A) `public.generic_operation_artifact_expected_facts_valid_v1` 漏加 `'contact-email-find-prospeo/v1'` 导致 Prospeo v2 出网成功后落账报 `GENERIC_OPERATION_ARTIFACT_INVALID`；(B) `contact-enrichment-safety-tools.ts` 将 Hunter/Prospeo 确定性非计费 4xx（400/404/422/451）一律折叠为 `unknownResult()`（HTTP 500 `BUDGET_OPERATION_REPLAY_UNAVAILABLE` 且无脱敏状态码日志），同时 Hunter 默认 `8s` 超时偏紧且 `normalizeEnrichedEmail` 未开启同集团跨国别 TLD 容错导致 `@enpal.de` / `@memodo.de` / `@centroplan.de` 被拒收；(C) `loadContactEnrichmentTargets` 与 `GET /canonical-companies/:id` 未过滤历史 `switchboard`/单 token 占位联系人，且 `executeView` 中途异常退出时遗留同执行未启动的 `ADMITTED` 步骤导致 `contact_enrichment_execution_step_inflight_fence_key` 锁死同公司重跑。
- 改动：
  1. 新增向前追加 Prisma 迁移 `packages/db/prisma/migrations/20261125163000_prospeo_artifact_expected_facts_allowlist/migration.sql`，在 `public.generic_operation_artifact_expected_facts_valid_v1` 中加入 `WHEN 'contact-email-find-prospeo/v1'`（六项 HTTP facts 必须全 NULL），严格保留函数签名、`IMMUTABLE`、`SET search_path = pg_catalog, public, pg_temp` 与 `REVOKE ALL` 零授权口径（并确认 Emailable/ZeroBounce 走 `typed_projection` 经 `execution_receipt_facts_valid_v1` 放行，不依赖该 artifact 函数）。
  2. 在 `contact-enrichment-safety-tools.ts` 仅对 finder（Hunter/Prospeo）放行确定性 4xx（400/404/422/451）交由适配器解析为 `miss` 并记录无 PII 的 provider/状态码诊断日志，同时保留 5xx/401/403/429/网络超时/验证器非 2xx 及畸形载荷 fail-closed；在 `hunter.provider.ts` 与 `prospeo.provider.ts` 补齐确定性 4xx JSON 语义解析（拒绝鉴权/欠费/畸形体）、将默认超时放宽至 15s，并在 `hunter.provider.ts` 与 `enrichment-domain-commit.ts` 开启同集团跨国别 TLD 邮箱校验（`allowCorporateGroup: true`）。
  3. 扩展 `isGenericSwitchboardContact` 识别 `Company Switchboard`/`Switchboard`，在 `loadContactEnrichmentTargets` 双层过滤 `switchboard` 占位行与少于 2 个有效拉丁人名 token 的占位联系人，在 `GET /canonical-companies/:id` 经 `filterDecisionMakerContacts` 剔除占位行（保留原有合成来源隔离校验），并在 `contact-enrichment-safety.composition.ts` 于 `EXECUTE` 异常退出时安全释放同执行未启动且 `budget_operation_id IS NULL` 的 `ADMITTED` 步骤。
- 测试：通过 10 个核心受影响 Vitest 套件（`enrichment-safety.migration`、`hunter.provider`、`prospeo.provider`、`contact-enrichment-safety-tools`、`enrichment-domain-commit`、`contact-quality-filter`、`enrich-company-contacts`、`company-channels`、`discovery.service.synthetic`、`contact-enrichment-safety.composition`，257 passed / 8 PG-gated skipped）、`execution-control-error.static` / `git-reviewed-evidence-acceptance` / `development-candidate-lifecycle`（43/43 passed）、`pnpm --filter @global/api build` 及全量治理快门（`execution-authority-policy`、`check-file-budgets`、`governance-module-boundaries`、`governance-unsafe-raw-sql`、`governance-verify`、`copy-fixed-source-impact`、`governance-document-drift`、`docs:verify`、`gitleaks`）；本地全量 vitest 1,014/1,017 非跳过文件通过（其余 3 个为宿主机 Node v22.23.1 低于 Astro `>=22.23.4` 及 worktree `packages/contracts/node_modules/zod` 本地环境缺省，交由 GitHub Actions CI 全量跑绿）。
- 未做：未修改任何 `durable-result-strategies.json` sha256 锁定核心文件（含 `tool-broker.ts`），未直接对现网 `global_dev` 执行数据库迁移（待合并发版由 `gctl switch-backend --with-migrations` 执行并在现网复验 Prospeo v2 与双商业验邮 `VALID` 落库）。
