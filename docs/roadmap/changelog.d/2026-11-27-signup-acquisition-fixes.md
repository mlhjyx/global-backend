- 起因：买家画像限制了可选角色，模型生成后逐条保存评分规则会耗尽数据库事务。大 PDF 同步识别超时后反复提交任务，官网页面的版权声明和通用文案也可能进入待确认事实。
- 改动：
  - 保留用户显式选择的买方角色，约束发给模型的角色文本体积，批量保存画像附表，沿用租户事务及模型结果回执。
  - 本机 PDF 识别按任务 ID 提交、查询和取回，暂时故障后复用同一任务，兼容在飞工作流。
  - 验证官网引文位置，筛掉版权、导航、宣传语和通用反馈文案。
- 测试：画像、预算旁路、文档入库和官网理解定向测试通过。隔离 PostgreSQL 验证 104 条画像明细一次保存，隔离 Temporal 与 PostgreSQL 验证文档状态查询中断后继续同一个任务。
- 未做：已存公司事实复核、历史文档重试和生产操作留待发布验证。
