- 起因：存量 `judgment_record` 在 ICP 升级（如 v3 放开 `process_required=false`）或 PR 1.7B-1 接入官方 EU VIES T1 核验后已过期，且离线脚本 `rejudge-batch.mts` 仅按 `(promptHash, rubricVersion)` 筛选会漏掉全部 `input_digest` 变化公司，也不允许跳过执行预算授权直接调模型。
- 改动：
  1. **专用执行预算用途 `icp.rejudge` 与两阶段迁移**：新增前向迁移 `20261126120000_icp_rejudge_purpose_enum`（事务外追加枚举值）与 `20261126120100_icp_rejudge_purpose_use`（同步更新 `execution_budget_authority_kind_shape_check`、`execution_budget_authority_admission_lease_check` 与 `consume_workspace_execution_authority` 的 60 分钟准入租约，保持 `SECURITY DEFINER` 与 `search_path` 不变）；同步更新 `schema.prisma`、`execution-budget-authority.types.ts`、`execution-budget-binding.ts`（`WORKSPACE_PURPOSES`）、`execution-budget-grant.verifier.ts`、`execution-budget-request-scope.ts`、`workspace-technical-budget-envelope.ts` 与 `workspace-technical-budget-quote.controller.ts`（含 `icp-rejudge-budget-request.ts` 严格 fail-closed 参数校验，禁止静默 clamp，按 `4×Panel × 2×Wire` 计算 `$1.60/$1.66/家` 预留包络）。
  2. **三条件精准收敛候选筛选与审计重判端点**：新增 `discovery/judgment/rejudge-candidates.ts`（`needsWebsiteV2` / `needsViesBackfill` / `needsDigestRejudge`，过滤 `SUPPRESSED` 与德企等 VIES 公开匿名国别，重复调用自动收敛返回 `409 NO_REJUDGE_CANDIDATES`）与 `icp/icp-rejudge.service.ts`、`icp/icp-rejudge.dto.ts`，在 `IcpController` 挂载 `POST /api/v1/icps/:icpId/rejudge`（要求 `JUDGE_CONTRACT_MODE=enforce`、两段式 `verifyWorkspaceGrant` 零消耗预检 + 单事务 `consumeVerifiedWorkspaceGrantInTransaction(authority, tx)` + `assertFreshExecutionBudgetBinding` + Outbox `LeadRejudgeRequested`）。
  3. **Outbox Relay 与 Temporal `rejudgeWorkflow`**：在 `relay/event-registry.ts` 注册内部命令 `LeadRejudgeRequested`，新增 `relay/rejudge-command.ts` 校验并按 `REJECT_DUPLICATE` 派发 `rejudgeWorkflow`；新增 `temporal/rejudge.workflow.ts`（零模块级数值常量，`retry: { maximumAttempts: 1 }`，遇致命预算错误立刻停批）与 `temporal/rejudge.activities.ts`（支持可选 `website-profile/v2` 刷新、经 `corroborateCompanyForRejudge` 刷新 T1/T2 核验并在 VIES 非瞬态未命中时通过受抑制保护的 CAS 合并写入分段哈希标记 `website_profile._vies_attempted`、严格三分 `runId` 隔离：`judgeFitCompany` 传 `binding.accountKey`、`persistJudgmentRecordInTransaction` 落 `run_id = NULL`、`QualifyRequested` payload 仅含 `{ rejudgeId }`、保护人工 `QUALIFIED`/`CONTACTED`/`CONVERTED` 线索不被降级）。
  4. **契约与操作手册**：重新导出 `packages/contracts/openapi/openapi.json`，更新 `docs/backend/judgment-rejudge-batch.md` 区分 `estimatedCostMicros` 与 `requiredCapMicrousd` 口径。
