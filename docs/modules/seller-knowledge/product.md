## 2. 模块定位与边界

### 2.1 用户与目标

- 服务用户：卖家企业（出海工厂/贸易商）的运营者与管理员。
- 要解决的问题：卖家的公司、产品、目标市场与产品资料散落在各处；引擎理解只读官网，ICP/外联拿不到上传资料。
- 期望结果：注册引导即建立公司档案；上传产品资料后自动解析、检索、抽取事实并经人工审批；后续理解/ICP/外联/建站都从同一空间取用。
- 在产品中的责任：模块 02 是卖家事实的**唯一 SoR**；其他模块只消费，不另建副本。

### 2.2 负责范围

| 范围 | 负责内容 | 完成条件 |
| --- | --- | --- |
| 当前设计覆盖 | 公司档案（含产品/目标市场）、资料库（上传/解析/分块/检索）、事实抽取与审批、检索 API | 上传→解析→检索命中；资料事实可审批；ICP 能引用资料 |
| 后续范围 | 多品牌/集团档案、资料版本对比、站点资料中心复用（M2 重启） | 建站线重启并经产品负责人拍板 |

### 2.3 明确不做什么

| 明确不做什么 | 原因 | 承接 |
| --- | --- | --- |
| 原始资料进入平台共享绿库 | D9/B4 红线：资料只在租户空间消费 | 平台学习层只消费脱敏衍生物（Phase 8） |
| 自动替用户判断事实真伪 | 证据必须可回溯、人工审批 | Claim 审批模型 |
| 资料库做通用网盘 | 只服务外贸获客与建站 | 不做 |

| 术语 | 定义 | 说明 |

| 公司档案 | CompanyProfile：卖家自己的公司事实 | 唯一 SoR；Site.profile 是投影 |

## 4. 模块流程

```text
注册引导 → 公司档案（名称/官网/行业/核心产品/目标市场）
  → 上传资料（产品目录/手册/报价单/认证/案例）
  → 解析（Docling）→ 分块 → 嵌入（BGE-M3）→ 可检索
  → 事实抽取 → Claim/Offering（带证据、quote、hash）→ 人工审批
  → 下游消费：公司理解 / ICP / 外联草稿 / 建站（后期）
```

## 5. 子功能设计

### 5.1 公司档案（D12/D16）

- 字段：公司名（中/英）、官网（可选）、行业、核心产品 1–5、目标市场（ISO-3166）、业务邮箱、简介。
- 规则：官网可选（D17）；无官网公司也能建档与理解（靠资料）；公司档案唯一，空间名从档案同步。
- AC：引导完成即档案完整度 100%；无官网也能进入理解与 ICP。

### 5.2 资料库（D7/D8/D9）

- 上传：PDF/DOCX/PPTX/TXT/MD，单文档 ≤50MB；presign/commit；魔数校验；sha256 去重；空间配额（默认 500 份/2GB）。
- 解析：Docling → markdown → 结构化分块（标题/表格）；BGE-M3 1024 维 → pgvector HNSW；失败可重试、状态可见。
- 检索：向量 + 关键词混合；返回片段、文件名、出处、相似度；供理解/ICP/外联调用。
- 删除：软删 + 恢复窗口；chunk/向量/对象随删；DSR 物理擦除。
- AC：上传→ready 状态可查；检索只命中本空间本公司的资料；跨空间 404；删除后不可检索。

### 5.3 事实抽取与审批（D8）

- 抽取：每份文档解析完成后自动抽取 Claim/Offering（evidence 必填、引用原文）；失败可见、可重试。
- 审批：Claim 进入 `NEEDS_REVIEW`；管理员/成员审批；文档删除后相关 Claim 自动过期。
- AC：每条 Claim 可点开到原文 quote；未审批事实不被下游当事实消费；审批留痕。

### 5.4 资料消费（D11）

- 公司理解：官网抓取 + 资料摘要双输入，任一可用即继续。
- ICP：提示词包含档案事实、Offering attributes、已批准 Claim、资料摘录（带出处、未审批标注）。
- 外联草稿：检索产品/认证/案例片段作为 selling points。
- AC：带资料的公司 ICP 初稿引用资料事实；外联草稿引用产品资料；无资料时行为不变。

## 6. 与其他模块的关系

- 模块 01：空间隔离与权限。
- 模块 03/04：消费卖家事实；不反向写入。
- 模块 05（建站）：M2 重启后消费本模块资料，不再维护独立 KB。

## 7. 验收标准

| 编号 | 验收 |
| --- | --- |
| AC-SK-1 | 引导完成即公司档案可用；无官网可建档 |
| AC-SK-2 | 上传 PDF/DOCX 后自动解析、分块、嵌入、可检索 |
| AC-SK-3 | 文档事实抽取带原文证据，审批后可被 ICP/外联消费 |
| AC-SK-4 | 跨空间检索返回 0 行；删除后不可检索且对象异步清理 |
| AC-SK-5 | DSR 删除公司/资料后，衍生物（chunk/向量/对象）全部清除 |
