## 2. 模块定位与边界

### 2.1 用户与目标

- 服务用户：卖家企业（工厂/贸易商）。
- 要解决的问题：出海企业缺少可信的独立站与询盘入口；现有 Site Builder 已建成 M1 但产品线冻结。
- 期望结果（重启后）：资料→站点→发布→询盘的闭环；当前不承诺。
- 在产品中的责任：模块 05 负责站点与公开输出；不拥有卖家事实（模块 02）。

### 2.2 负责范围

| 范围 | 负责内容 | 完成条件 |
| --- | --- | --- |
| 当前设计覆盖 | intake、站点/档案、素材、KB、构建（Temporal DAG）、SiteSpec、Release/预览 | M1 as-built（已收口） |
| 后续范围 | M2（编辑器/发布/域名/询盘/PublishReview）、M3（视频/店铺导入/诊断） | 建站线重启并经产品负责人拍板 |

### 2.3 明确不做什么

| 明确不做什么 | 原因 | 承接 |
| --- | --- | --- |
| 自由代码生成/自由 Planner | 封闭组件库 + SiteSpec 安全边界 | 不做 |
| 独立维护第二套卖家知识库 | D7/D16：模块 02 为唯一 SoR | 重启后消费模块 02 |
| 公网发布/域名/询盘（一期） | 未实现 | M2/M3 |

## 3. 术语与核心对象

| 术语 | 定义 | 说明 |
| --- | --- | --- |
| Site | 站点 | 一 workspace 一 site（v1） |
| SiteSpec | 封闭组件规格 | 1.0 as-built / 1.1 目标 |
| SiteVersion / SiteRelease | 版本与不可变发布 | 指针晋级 |
| Asset | 素材（logo/产品图/证书等） | presign/commit；引用保护 |
| KB | 建站知识库 | Docling+BGE-M3+pgvector；后续并入模块 02 |

## 4. 模块流程

```text
注册 intake（公司/行业/产品/目标市场）
  → Site + demo 构建（确定性）
  → 资料上传/向导 → KB
  → 品牌/文案/组装 → SiteSpec → 渲染 → Release
  → 预览/发布（M2 未实现）
```

## 5. 子功能设计

### 5.1 Intake 与档案

- 字段：公司名中/英、行业、产品 1–5、目标市场、官网、业务邮箱；创建 CompanyProfile + Site；**必须触发公司理解**（P0 修复）。
- AC：注册即建档；无官网可继续；公司理解被触发。

### 5.2 素材与 KB

- 素材：presign/commit、魔数、sha256、引用保护删除；doc 类进入 KB。
- KB：Docling→分块→BGE-M3→pgvector；只读状态接口（GET kb/status）。
- AC：上传→ready；删除受引用保护；检索按空间。

### 5.3 构建与发布

- 固定 DAG（brand→asset→copy→assemble→quality）；SiteSpec 封闭组件；Release 不可变 + 指针晋级。
- AC：M1 已收口；发布/域名/询盘未实现。

## 6. 与其他模块的关系
