> 模块技术方案：[technical.md](technical.md)

## 定位

平台是 AI 产品，需要一层**受控技能运行时**：行业技能以标准包（SKILL.md）登记、按版本钉住、可被运营启停，并让「每个模块的能力都能以统一契约被调用」。它不是「超级 Agent」——领域 AI Task + 确定性 Workflow + Tool Policy + Human Gate 的分工不变（PRD §9）。

## S0 提供什么

- 三个存量技能有正式包规范与版本身份：公司事实抽取、公司产品/服务抽取、候选公司资格判定。
- 运行时空转：同样输入得到同样的模型行为（零行为变化）；但技能未登记/被停用时**不可执行**（fail-closed）。
- 运营可一键停用/恢复任一技能（平台级），或对单个工作空间停用（覆盖）；解析结果留下不可变审计快照。
- 为 S1 的 Pack v1（行业/市场/合规规则包 + Golden Set + 新技能）与后续触达/报价技能打地基。

## 边界

- 不改任何提示词、模型路由、预算或对外事件；不发送任何外部内容。
- 技能脚本不在本层执行；租户自定义技能与市场是 S3。
- 用户可见面暂无变化（S0 是底座；能力仍经既有获客链路呈现）。
